# 监测时间段

在「监测规则 → 监测开启时间」选择「仅在自定义时间段开启」。

- 使用「添加时间区间」添加多个区间，最多 16 个。每行分别设置开始、结束时间，可以删除多余区间，至少保留一个。
- 例如 `13:00～14:00` 和 `22:00～07:00`，表示每天午休和夜间开启；后者跨到次日。
- 进入任意区间即开启，重叠或相邻区间合并判断，不会因同时匹配多个区间重复发送通知。
- 开始时刻包含在区间内，结束时刻不包含。例如 `13:00～14:00` 在 14:00 停止；开始和结束不能相同，要全天监测请选「全天开启」。
- 时间按北京时间，每天重复。软件及监测任务需保持运行。演示模式仍不受监测时段限制。
- 点击「保存监测规则」或「保存全部设置」永久保存；切换全天模式后仍保留自定义区间，方便切回。

旧版本单个时间段会在界面自动显示为一行，原有配置仍可读取。规则备份包含多个时间段；导入旧版单区间备份时，会替换当前多个区间。
