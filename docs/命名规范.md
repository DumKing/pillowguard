# 枕安 / PillowGuard 命名规范

中文产品名为「枕安」，英文产品名为 **PillowGuard**，与 GitHub 项目保持一致。不要用中文拼音作为新的英文标识。

| 使用位置 | 规范名称 |
|---|---|
| 中文界面、窗口标题、应用显示名 | 枕安 |
| 英文品牌、英文介绍 | PillowGuard |
| GitHub 仓库、Rust 包名、命令行程序、Docker 服务 | pillowguard |
| 环境变量 | `PILLOWGUARD_*` |
| Mac 应用 | `枕安.app`，内部启动文件 `pillowguard` |
| Windows 程序 | `PillowGuard.exe` |
| Windows 便携包 | `PillowGuard-Windows.zip` |
| Mac 安装包 | `枕安-版本-Mac-架构.dmg` |
| 图标文件 | `PillowGuard.icns`、`PillowGuard.ico`、`pillowguard-icon-尺寸.png` |
| 规则备份格式标识 | `pillowguard-rules` |
| 新浏览器偏好键 | `pillowguard-page` |
| macOS / Windows 数据目录名称 | 枕安 |
| Linux 数据目录 | `~/.local/share/pillowguard` |

兼容升级时，保留旧环境变量、旧备份格式和旧浏览器偏好的读取入口；新导出与新示例只使用上述名称。旧数据目录应整体迁移，不能因改名重新创建一套空配置或覆盖已有新目录。

应用内部标识 `com.laoren.shouwang` 和已部署的 Docker 数据卷 `laoren-data` 是升级兼容标识，保留以延续系统授权和原有数据，不作为产品品牌。GitHub 仓库链接和用户自行指定的工作目录不因中文改名而更换。
