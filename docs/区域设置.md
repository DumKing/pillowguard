# 区域设置

在「实时监测」画面上选择床位、床沿、地面或卧床头部区域。

- 拖动带编号的圆点，可以将四边形调整为梯形，贴合斜俯视画面。
- 点击「重新描绘」，沿实际边界依次点选 3～12 个顶点，再点「完成描绘」。支持凹多边形，不要求是矩形。
- 「撤回上一点」修正未完成的描绘；「取消描绘」恢复原有区域。
- 点击已有顶点可选中，使用「添加顶点」在它与下一顶点之间插入一点，再拖动；「删除选中顶点」减少顶点，至少保留 3 个。
- 床沿和地面可以清除。床位必须保留有效区域；规则页的「重置床位区域」会恢复默认四边形。
- 点击「保存全部设置」永久保存。未完成的描绘需要先完成或取消才能保存。边界交叉、重叠、重复顶点、过小或画面外的区域不能保存，非法拖动会撤回。

床位按多边形和人体框的实际相交面积判断，仍沿用人体框重叠至少 15% 的门槛。外接矩形的空白角落不会被纳入床位范围。

当前仅启用持续坐起提醒，床沿和地面区域只保存备用，不启用站起、离床或跌倒告警。改变床位形状或视频源会清除原有头肩位置校准，需要重新采集卧床与坐起参考；改变备用区域不清除校准。

旧版矩形配置可继续读取，并在页面上显示为 4 个顶点。保存后采用顶点坐标；旧矩形转换为等价四边形不会清除校准。区域数据以画面宽高的比例保存，窗口缩放不改变实际位置。

## 疑似卧床辅助（实验性）

选择「卧床头部区域」，只沿躺卧时头部的位置描绘一小块区域，并留少量转头余量，保存即可启用。不要把整个床位或被子隆起范围当作头部区域。可以用「清除区域」关闭该辅助；更换摄像头来源也会清除此设置。

辅助检测使用独立的头部模型和连续 3 秒的位置证据，检测约每秒采样一次。可信头部应在床位内，且大部分位于所选头部区域；有多个可信头部、位置明显改变或证据消失时清除。视频超过 2 秒没有更新也会清除显示。

显示「疑似卧床」时，底层姿态仍是无法判断，确认人数不增加，也不会建立躺卧基线、解除已有告警或关闭异常提醒。无需夜间实时人工确认。空床、被子或静止本身不能触发这项显示。当前尚未完成红外实景准确率验收，可能继续显示无法识别。
