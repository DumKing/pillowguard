# 枕安 0.3 当前验收范围

当前仅持续坐起提醒。早期起身、站起、床沿、离床、跌倒均不是当前启用的告警类型；床沿、地面可保存区域备用。

| 能力 | 已完成的验证 | 限制 |
|---|---|---|
| Rust 本地推理与桌面窗口 | Intel Mac 构建、ONNX 自检、Tauri 本地服务 | 不需要 Python 运行环境 |
| 本机摄像头 | Mac AVFoundation 连续收帧 | Windows / Linux 摄像头仍需实机验证 |
| 坐起状态机 | 躺卧、坐起持续时长、冷却、短遮挡、事件去重单测 | 肩髋竖直判断可能把站姿归入坐起 |
| 多人暂停 | 第二人阈值、人体框去重、遮挡人数不确定、多人恢复单测 | 被子、反射和特殊机位仍需实景复核 |
| 可选未知转坐起 | 启停、持续未知、重新布防、冷却和多人清除单测及模拟通知 | 新进入床位的人也可能触发 |
| 头肩辅助校准 | 可见锚点、矛盾判断、稳定采样、持久化与失效条件验证 | 真实床位需采集参考，头肩全遮挡仍无法判断 |
| 不规则区域 | 凹多边形、边界相交、空白外接角落、交叉与过小拒绝单测 | 床位人数按人体框重叠 15% 判断 |
| 区域操作与保存 | 页面描绘、增删顶点、保存，三种区域重启恢复和旧矩形兼容回归 | 只有床位区域参与当前告警 |
| 多时间区间 | 多区间并集、跨午夜、边界、重叠、16 个上限、持久化与旧配置迁移 | 按北京时间每日重复，需保持监测任务运行 |
| 多渠道通知 | 同类多条、启停、单渠道测试、删除、凭据保留和清除回归 | 平台接口接受不等于接收人阅读 |
| 企业微信应用通知 | 模拟获取凭证、缓存、过期清理、部分接收对象错误、配置重启 | 真实应用需配置可见范围及可信 IP 后测试 |
| 小爱音箱 | 用户已实际试听所配置的播放文本实体 | 每次请求前检查实体；新设备仍需手动验证 |
| 升级音箱连播 | 模拟三次播报、多人中途取消、请求失败不重试、配置重启 | 播放结束时间是估算，已提交的播放无法撤回 |
| 异常提醒 | 持续无法判断、恢复去抖、独立开关、启动失败规则验证 | 可单独关闭，界面仍显示异常 |
| 演示与回放 | 演示状态切换、模拟通知、回放时长进度与视频时间判断 | 演示会真实通知，回放不自动发通知 |
| 配置与历史 | 凭据独立保存、查看/复制/清除、历史重启、CSV 与规则备份检查 | 本地凭据未加密 |
| Mac 安装包 | 镜像完整性、应用与视频组件签名、图标、模型自检、包内文件清单 | 本机临时签名，未 Apple 公证 |

当前 Rust 单测共 60 项；接口回归使用临时目录和本地模拟接收端。Windows、Apple Silicon Mac 与 NAS 提供源码或构建配置，不将源码可编译或 CI 检查等同于对应设备安装、摄像头和长期运行验收。夜间实景效果仍需在实际床位复核。

疑似卧床辅助新增了头部旋转坐标还原与去重、连续证据、证据消失、区域变化、时间跳变和多人清除测试；独立头部模型通过普通正样本及空白负样本推理检查。清晰红外躺卧样本通过局部细节识别可检出可信头部；被子及空枕头局部负样本未检出可信头部。尚未完成坐起和完整夜间误报、漏报验收，不能据此承诺识别准确率。

后续实景验收应包含同机位的空床、被子隆起、有人躺卧、翻身、头部遮挡、坐起、照护人进入及断流。分别记录误显示与漏显示，检查“疑似卧床”不改变坐起基线、去重、重复、升级和异常提醒。图像与身份特征不随软件分发。

告警留图已验证五次轮换、重启读取、重复事件去重、无新鲜画面提示及文件权限；界面检查覆盖空列表、放大查看、关闭和刷新。抬腿撑被子的防护覆盖缺失头部、头身方向矛盾及独立头部位置不一致，实景效果仍需持续核查。

命名统一为枕安 0.3.1：配置目录升级保留凭据、历史和截图，已有新目录不被覆盖；新规则导出使用 zhenan-rules，同时接受旧版 shouwang-rules 导入。保留旧环境变量作为兼容入口。
