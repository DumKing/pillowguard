# 企业微信应用通知

在软件「告警通知」中选择「企业微信应用通知」，点击「添加渠道」。可同时保留群机器人，也可添加多个应用通知渠道。

1. 在企业微信管理后台创建自建应用，设置应用可见范围，让接收成员可以使用该应用。
2. 从「我的企业」取得企业 ID（CorpID）；从自建应用详情取得 AgentID 和 Secret。
3. 在软件内填写这三项。Secret 留空保留已保存的值，输入框右侧支持查看、复制和清除，点击保存后永久生效。
4. 接收成员填写成员的 UserID，不是姓名或手机号；多个用 `|` 分隔。也可填写部门或标签的数字 ID，至少填写一类。`@all` 表示应用可见范围内的全部成员，使用前先确认范围。
5. 根据应用后台要求，将运行软件时的网络出口公网 IP 配置为「企业可信 IP」。软件当前直接连接企业微信接口，不继承系统 HTTP 代理。更换网络可能需要更新可信 IP。
6. 保存后点击「测试此渠道」，在接收人的企业微信应用消息中核实。

发送坐起告警、演示告警和启用的异常提醒时，应用通知与其他启用渠道同时发送。升级连续播报仅使用音箱，不会使应用消息跟着连发；普通重复提醒仍按规则发送。

软件在内存中缓存应用 access_token，并在到期前重新获取，不将它写入配置。应用 Secret 保存在本机受权限保护的凭据文件内（未加密），不会进入活动日志、普通状态或规则备份。只有用户点击查看或复制时才读取 Secret。

接口返回成功不代表成员已阅读；部分成员无效或无权限会单独提示，不能认定全部送达。请求超时或失败不会自动重发；凭证过期会清除缓存，在下一次通知时重新获取。

接口参考：[获取 access_token](https://developer.work.weixin.qq.com/document/path/91039)、[发送应用消息](https://developer.work.weixin.qq.com/document/path/90236)。这项功能发送应用文字消息，不发起语音通话，也不接收回复或处理确认按钮。
